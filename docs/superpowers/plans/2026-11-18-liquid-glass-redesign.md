# Liquid Glass Redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Restyle the whole app in the approved Liquid Glass look, keep the exercise animations, and rebuild the README around framed renders of the real app.

**Architecture:** This is a CSS restyle in `src/template.html`, driven by the existing token and `data-scheme`/`data-accent`/`data-contrast` system, plus one new Stats card in `src/app.js`. Real backdrop blur goes only on surfaces that content scrolls under: header, tab bar, settings sheet and toast. Cards sit over a fixed, unmoving colour wash, so they get a translucent fill and an edge highlight without blur, which looks the same and costs nothing. A Node + Playwright script renders the README images from the built app with demo data.

**Tech Stack:** Vanilla HTML/CSS/JS PWA, Python build (`src/build.py`), Playwright and `node:test` tests (`tests/app.test.js`).

**Spec:** `docs/superpowers/specs/2026-11-18-liquid-glass-redesign-design.md`

## Global Constraints

- Liquid Glass is the only look. There is no style switch in Settings.
- Auto/Light/Dark/Black modes, the five accents (clay, ocean, forest, violet, graphite) and high contrast all keep working.
- High contrast turns glass solid: no translucency and no backdrop blur.
- `backdrop-filter` is always paired with `-webkit-backdrop-filter`.
- The CSP stays `script-src 'self'`, with no inline script.
- `prefers-reduced-motion: reduce` stops the cross-fade, and tapping `.fx` toggles `.end`. Both are existing behaviour that must survive.
- No platform logos, Apple device artwork or Apple fonts. The phone frame is drawn in CSS.
- README images are static PNGs and can be regenerated by a script.

## Review Focus

- Bright light and light mode: body and muted text on glass must stay at 4.5:1 or better against the surface over the lightest part of the wash. Test in Task 1.
- A browser without `backdrop-filter` support: bars must fall back to a near-opaque fill, not stay see-through. Test in Task 1 (`@supports not` fallback check).
- Black mode: the wash must not wash out true black. The background stays `#000`, with only a faint accent glow. Test in Task 1.
- Reduced motion: the preview card on Stats must obey it like the Log cards do. Test in Task 2.
- A next session whose first exercise has no animation image: the preview card must still render without a broken image. Test in Task 2.
